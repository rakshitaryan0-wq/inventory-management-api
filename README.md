## 📝 Project Overview
A RESTful backend API built to manage a library or inventory system. This project demonstrates the fundamental principles of backend development, showing how a server processes incoming network requests, updates data, and sends the correct responses back to a client.

## ✨ Features
* **In-Memory Data Storage:** Lightweight, array-based data management for immediate testing without requiring a database setup.
* **Complete CRUD Operations:** * `POST` - Create new inventory items
  * `GET` - Read/Retrieve all items or specific items by ID
  * `PUT` - Update existing item details
  * `DELETE` - Remove items from the inventory
* **JSON Formatting:** Standardized JSON-based request and response handling for seamless client-server communication.

## 🚀 Technologies Used
* **Node.js** (JavaScript Runtime)
* **Express.js** (Backend Web Framework)
* **Thunder Client / Postman** (API Endpoint Testing)
